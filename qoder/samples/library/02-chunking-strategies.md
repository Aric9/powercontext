# 面向长文档的分块策略

## 研究问题

检索质量的上限往往由分块决定。块太大时一个块混入多个主题，块太小时缺少上下文。本文比较章节切分与固定窗口切分。

## 章节切分

按 Markdown 标题切分保留了作者的组织结构。我们在 120 篇论文笔记上比较，章节切分比 512 token 固定窗口的
Recall@10 高 8.7 个百分点；当章节超过 1200 字符时再按段落二次切分，效果最好。

## 窗口与重叠

固定窗口实验显示，512 token、15% 重叠是质量与存储成本的折中点。重叠低于 8% 时会切断跨段论证，
高于 25% 时重复块会挤占 top-k。小于 200 字符的块噪声明显，建议与相邻块合并。

## 建议

优先按标题切分，章节过长再按段落切；块大小控制在 600–900 字符，重叠不超过 120 字符，并为每块保留起止行号。
